أَثَر مع مساعد Gemini الذكي

التشغيل على Windows:
1) فك ضغط الملف.
2) افتح مجلد athar_ai_project.
3) أنشئ نسخة من .env.example وسمّها .env.
4) افتح .env وضع مفتاح Google AI Studio بعد GEMINI_API_KEY= فقط. لا تشارك هذا الملف أو المفتاح.
5) افتح CMD داخل المجلد ونفّذ: npm install ثم npm start
6) افتح http://localhost:3000

المساعد يستخدم Gemini API من Google عبر الخادم، والمفتاح لا يظهر في المتصفح. الخطة المجانية وحدودها وتوفر النماذج تخضع لشروط Google وقد تتغير؛ ليست استخدامًا غير محدود أو ضمانًا دائمًا للمجانية.
إذا ظهر خطأ 429 فهذا غالبًا حد استخدام/حصة؛ وإذا ظهر 400 أو 403 فتحقق من المفتاح وإعدادات Google AI Studio.
لا ترفع ملف .env إلى GitHub ولا ترسله لأي شخص.
